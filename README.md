# AI 求职复习包

给 Codex 一个公司和岗位名，或贴一份岗位描述（JD）。它会搜索公开的笔试和面试经验，核对原帖，再把散落的考点整理成可以直接学、直接练的复习资料。

## 安装

需要一个能使用网页搜索的 Codex 环境。技能本身只包含 Markdown 指令，无需单独配置搜索 API 密钥。

```bash
git clone https://github.com/anyan001121-dot/ai-exam-prep.git "${CODEX_HOME:-$HOME/.codex}/skills/ai-exam-prep"
```

已有同名技能时，更新原目录中的 `SKILL.md` 即可。安装或更新后，在 Codex 中开启一个新聊天。

## 使用

在聊天中输入：

```text
$ai-exam-prep 帮我准备网易互娱游戏数值策划笔试。我只有两晚，请搜索公开经验帖，给我复习顺序、练习题和解析。
```

也可以附上 JD 或笔试通知。通知里的题型、时长和分值会用于制定本次的练习安排。想了解岗位日常工作或准备面试时，可以直接写明。

## 你会拿到什么

- 按岗位和招聘批次标注的考核概况，附可回看的原帖链接。
- 按优先级排列的复习主题，注明是历史回忆、岗位要求推断，还是相近岗位参考。
- 可以先做后对答案的原创练习，附解题步骤和常见错误。

历史经验反映对应的招聘批次，样本覆盖会随岗位和公开资料而变化。网页搜索不可用时，可以把已有经验帖或 JD 贴进聊天继续整理。
